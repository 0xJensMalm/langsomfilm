# Langsom Film

Website prototype for Langsom Film: a poster carousel where each poster flips over to show film details, a flip-card bio, and a slow turtle walking along the bottom.

Plain HTML/CSS/JS, no build step. Open `index.html` or serve the folder.

- `index.html` – the whole site (markup, styles, script)
- `assets/` – posters, stills and portrait

## Editing (demo)

"Logg inn" in the footer opens an edit mode for adding/editing/reordering films and the bio. In this prototype any password works and changes are saved only in the visitor's own browser (localStorage). A real login and shared content need a CMS backend (e.g. Sanity or Decap CMS).
